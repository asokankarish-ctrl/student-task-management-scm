## Project Objective
The objective of this project is to provide a simple
web application to manage library books.

## Features
- Add books with title and author
- View books in a table
- Borrow available books
- Return borrowed books
- Remove books that are not borrowed
- Validate book title and author inputs
- Search books by title or author (case-insensitive)

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- src/ - Application source files
- tests/ - Test cases
- docs/ - SCM documentation
- Readme.md - Project information

## Setup Instructions
1. Open the project folder in VS Code.
2. Open src/index.html in a browser.
3. Add a book by entering its title and author.
4. Use the Borrow, Return, and Remove buttons.
